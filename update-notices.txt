#   schema: N   update-system version. Raise it only if the updater itself changes in a way that
#               older copies can't follow. Those copies then guide the user to a manual download.
#   latest: X   newest public version. Copies newer than this count as pre-release builds and
#               pause auto-update (so they are never downgraded).

#   TYPE      info      dismissible banner
#             warn      banner shown every session

#             ahead     marks pre-release versions (auto-update pauses)
#             block     this version must not be used (dialog with "Download update")
