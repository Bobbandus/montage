# Montage

Film editing suite for Windows, developed by **A+ Studios** (Alingsås).
GPU-accelerated playback and export, frame-accurate editing, free text placement with any installed font.

## Download
Get `Montage-Setup-<version>.exe` from [Releases](https://github.com/Bobbandus/montage/releases/latest).
Installed copies update themselves: new versions download in the background and install on restart.

## Update notices
[`update-notices.txt`](update-notices.txt) is read by every installed copy. Use it to post news,
warnings, or to send specific versions to a manual download. The format is documented at the top of the file.
